# Test Photos (placeholder content — NOT real club photos)

Free stock images downloaded from Unsplash, used only to populate the admin
panel and front office with realistic-looking data while testing locally
(player/user avatars, gallery albums, tournament pages).

**Do not use these in production.** Replace with real club photos before
going live, then delete this folder.

## Folders

- `avatars/` — 8 portrait headshots (square, 400×400) for testing admin
  user accounts and player profile photos.
- `gallery/` — 10 football action/match photos (1200×800) for testing the
  gallery album feature.
- `tournament/` — 6 trophy/podium/crowd photos (1200×800) for testing
  tournament pages and registration flows.

## How to use them

1. Go to the relevant admin page (Users, Players, Gallery, Tournaments).
2. Upload a photo using the existing upload control.
3. Pick a file from this folder via the file picker (drag-and-drop also works
   for the gallery uploader).
